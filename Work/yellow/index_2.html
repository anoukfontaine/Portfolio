Financial Planning Dashboard

Yellow is the New Green

Automating an error-prone and cumbersome controlling process.

Overview

Excel had supported financial planning for years. Power BI opened up new ways to automate the process and explore the data. The main challenge was learning a new tool while bringing everyone on board with a new way of working.

Note: To protect internal information, the illustrations and mockups have been simplified. The main dashboard mockup is fictional and illustrates the structure of the solution.

What
Multi-page Power BI dashboard
Role
End-to-end ownership of the project and product, from UX/UI design through Power BI development, rollout and long-term maintenance.
Users
Decision-makers, data analysts and operational teams within the Swiss federal administration.
Period
2 years part-time

  1. Observe

    Interviews, user journeys, user flows

  2. Design

    Information architecture, prototypes, data visualization

  3. Build

    Power BI DAX, data modelling, access, data connectors

  4. Test

    Usability testing, questionnaire, iterations

Problem

Everything, everywhere, all at once

Excel is a loyal companion for data nerds. But when every organisational need has led to yet another Excel cockpit, and a lack of trust has created a cemetery of file versions, the confusion in users’ eyes becomes all too real. Meanwhile, an endless queue of files needs updating. All drawing from the same data source: SAP. Export. Copy. Paste. Update. Over and over again.

Pain Point 1/3

Information was scattered across multiple manually maintained Excel sheets

Maintaining the files took time and reduced trust in the data.

Antidote

One Power BI application brings all financial information into one place

Accessible via a web link, with automatically updated data.

Pain Point 2/3

Answering a budget question meant rebuilding the same Excel views

Each new question meant another round of manual filtering.

Antidote

Shared filters let users explore the same data from different angles

Choose a year, country, or section and the charts and table update together.

Pain Point 3/3

A budget total gave little indication of what drove it

Finding the projects behind a figure meant opening another file.

Antidote

Users can go from a summary chart to the project-level details

The figures and their underlying records are available in the same view.

Impact

Cutting manual preparation work by 90% and achieving 100% satisfaction among primary users.
