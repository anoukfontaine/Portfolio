Financial Planning Dashboard

Yellow is the New Green

Automating an error-prone and cumbersome controlling process.

Overview

Excel had supported financial planning for years. Power BI opened up new ways to automate the process and explore the data. The main challenge was learning a new tool while bringing everyone on board with a new way of working.

Note: To protect internal information, the illustrations and mockups have been simplified. The main dashboard mockup is fictional and illustrates the structure of the solution.

What
Multi-page Power BI dashboard
Role
End-to-end ownership of the project and product, from UX/UI design through Power BI development, rollout and long-term maintenance.
Users
Decision-makers, data analysts and operational teams within the Swiss federal administration.
Period
2 years part-time

Problem

Numerous Excel-based financial cockpits and overviews scattered information across different platforms and tools, making it hard for users to find information and easy for errors to creep in.

Challenge

Scepticism

Finding a solution meant challenging deeply rooted habits and bringing everyone on board, including less obvious stakeholders.

Antidote

Big changes in big organisations don’t happen without stakeholder buy-in and management support. Winning people over, challenging scepticism and navigating roadblocks became just as important as designing a solution users would love.

  1. Understand

  2. Demonstrate value

  3. Deliver quick wins

  4. Involve early

  5. Communicate openly

Approach

User-centred

The initial situation screamed for automation and better user experiences. I had many ideas but if there’s one thing I’ve learned as a UX designer, it’s never to trust an assumption without putting it to the test. From the very first interviews and user journey mapping to prototypes and usability testing, users were never far from the drawing board.

Data-driven

Rethinking and redesigning a jungle of data to make it more accessible by applying data visualisation best practices is my cup of tea. But behind it all lay a less glamorous world of data models, calculations and technical constraints. Luckily, I’m rather stubborn. If I can see it in my mind, I want to see it on my screen. So I sought help where I could and learned what I needed along the way to make ambitious ideas tangible. A win-win for the project and my Power BI skills.

  1. Observe

    Interviews, user journeys, user flows

  2. Design

    Information architecture, prototypes, data visualization

  3. Build

    Power BI DAX, data modelling, access, data connectors

  4. Test

    Usability testing, questionnaire, iterations

Pain Point 1/3

Scattered information

Financial information was scattered across Excel files, making it hard to find the right figures and know which version to trust.

Solution

All in one

A central dashboard brings the essential figures together and gives users a single link to access them.

Pain Point 2/3

Untransparent numbers

Charts and tables showed the totals, but users struggled to see how they were calculated or which projects contributed to them.

Solution

Traceable amounts

Interactive visuals and a connected project list let users explore the figures and see which projects contribute to each total.

Pain Point 3/3

High maintenance

Updating Excel files took hours, sometimes days. Every manual step created another opportunity for errors.

Solution

Independent and automatic

A centralised data pipeline refreshes the dashboard automatically, replacing manual file updates and removing the need to rebuild reports each year.

Impact

Cutting manual preparation work by 90% and achieving 100% satisfaction among primary users.
